# UID / GID Utility Scripts

This directory contains scripts used for managing identities (users and groups) within a Viya deployment, specifically with how their UID/GID information is maintained.

* Generate / Load UID scripts - used to replicate the UID/GID information for users and groups across deployments.  These scripts (for example [generateUID.sh](generateUID.sh) and [loadUID.sh](loadUID.sh) are required in cases where UID/GID values are not present in the site's IdP. In these situations, Viya attempts to generate new UID values automatically for all identities - which may not match their file system settings. To assist with this, these scripts can be used to load the correct UID/GID values into the Viya authentication infrastructure in order to ensure permissions for those users are configured properly.

* Override UID scripts - required only in cases where a user's UID/GID values have been previously configured within the Viya authentication infrastructure and cannot be updated using the proper sas-viya CLI commands. Note these scripts should be used with caution, and should only be used in cases where after authenticating, the wrong set of UID/GID values were automatically generated for a given user.


## Workflow
These instructions assume that you have the CLI installed and configured

**NOTE** The endpoint where you run these scripts MUST be able to "see" all groups and users. Make sure sssd is configured with the appropriate filters. 

1. Fetch the list of users registered within the Viya deployment:
```bash
./identities/fetchUsers.sh --dir viya-identities
```

2. Generate the UID values for each user included in the output file generated by the above command. You may skip this step if you have a different process for obtaining the UID/GID values.
```bash
./identities/uid/generateUID.sh --user-file ./viya-identities/users/users.csv --output ./viya-identities/users/uid-values.csv
```

3. Load the UID values into the Viya deployment
```bash
./identities/uid/loadUID.sh --user-file ./viya-identities/users/uid-values.csv
```

4. To load GID values for primary and secondary groups, follow steps 1-3 above using the fetchGroups.sh / generateGID.sh / loadGID.sh scripts.
